WebGPU Hardware Acceleration

Instanced GPU quad rendering and analytical signed-distance field (SDF) shaders handle 5,000+ primitives with zero stutter or dropped frames.

Embedded SQLite Storage

Your work is saved locally into high-performance indexed SQLite and synced directly to ~/Documents/Vellum. No loss, no accounts, and instant project switching.

Professional Vector Editing

Bézier pen tool with smooth/broken tangent control, auto-layout flexbox engine, reusable components with overrides, and live CSS inspection.

100% Private & Offline

Vellum makes zero network requests. No user tracking, no telemetry, and no mandatory cloud updates. Your confidential designs stay on your hardware.

Native .vellum Document Format

Registered natively in macOS Finder. Double-click any .vellum file to open it. Pure, portable open JSON format readable by any script.

Dual-Mode: Desktop & Browser

Runs natively as an installed Mac app or as a zero-dependency static web app on GitHub Pages via IndexedDB fallback.
